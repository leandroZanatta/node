# O "pom" de cada pacote: o que ele PODE importar. Nada mais.
#
# Isto é o contrato que um módulo Maven imporia, num projeto que termina em um
# processo só e não ganharia nada com multi-módulo. Acrescentar uma aresta aqui
# é um ato consciente — do mesmo tamanho de editar um pom — e `ArquiteturaTest`
# reprova o build se o código importar o que não está declarado.
#
# A ordem abaixo é a ordem das dependências: quem está em cima não conhece quem
# está embaixo. O grafo tem de ser acíclico.
#
# baixa: baixar blocos e transações da rede (p2p, protocolo, rpc, sync).
# transformacao: aplicar esses dados ao catálogo e ao mercado.
# execucao: decidir e disparar transações sobre o que o mercado mostra.
# auditoria: registrar o que aconteceu (relatórios, diários, pagamentos, API).
# raiz: Main, que apenas compõe os quatro orquestradores.

exception:
vo:
util:          exception
baixa:         vo, util, exception
transformacao: baixa, vo, util, exception
execucao:      baixa, transformacao, vo, util, exception
auditoria:     baixa, transformacao, execucao, vo, util, exception

# A raiz compõe o node inteiro, então é a última: depende de todos e ninguém depende dela.
raiz:          baixa, transformacao, execucao, auditoria, vo, util, exception
